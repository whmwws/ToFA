# 社区行为准则

## 我们的承诺

ToFA 社区欢迎不同背景、经验水平和设备环境的参与者。无论贡献大小，都应获得尊重、清晰且可建设性的交流。

## 期望行为

- 对事不对人，尊重不同观点和实现方案。
- 提供可复现、可验证、对改进有帮助的反馈。
- 承认错误、尊重维护决定，并保护用户与贡献者隐私。
- 在 Issue、Pull Request、代码审查和发布讨论中保持耐心。
- 对安全、密钥和个人数据保持最高程度的谨慎。

## 不可接受的行为

- 侮辱、歧视、骚扰、威胁、持续纠缠或人身攻击。
- 发布他人隐私、真实密钥、验证码、激活码或签名材料。
- 故意误导他人执行破坏数据、关闭安全保护或泄露凭据的操作。
- 冒用项目、维护者或他人身份，或进行恶意推广。
- 公开未修复安全漏洞的细节，或以漏洞报告为条件进行勒索。

## 适用范围

本准则适用于项目仓库、Issue、Pull Request、Discussion、Release、社区交流，以及代表项目参与公共活动的行为。

## 举报与处理

涉及个人隐私、骚扰或安全的举报，请使用 [SECURITY.md](SECURITY.md) 中的私密联系渠道，不要在公开 Issue 中转发敏感内容。举报应包含相关链接、时间、截图和必要上下文，但应先遮盖个人数据与凭据。

维护者将根据影响与严重程度采取提醒、编辑或删除内容、关闭讨论、要求停止不当行为、限制参与，或向平台举报等措施。处理时尽量保护举报人与相关人的隐私。

维护者应以公平、一致和可解释的方式执行本准则，并可基于项目长期安全与社区利益调整讨论范围。
