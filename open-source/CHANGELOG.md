# 更新记录

本文件记录对使用者和贡献者有实际影响的变更。手机端与手表端统一使用纯语义版本号 `x.y.z`。

格式参考 Keep a Changelog，发布时使用 `x.y.z - YYYY-MM-DD`。

## 未发布

### 文档

- 集中整理贡献、安全、隐私、第三方许可、发布清单和 GitHub / Gitee 模板。
- 完善本地开源、双平台发布、签名、校验与维护手册。

## 0.2.5 - 2026-11-14

### 手表端

- 长按菜单的版本号移到页面最底部贴底显示，不再与上方提示文本挤在一起；圆屏 / 方屏布局、弦长内边距与进场动画保持不变。

## 0.2.4 - 2026-11-14

### 手机端

- 传递页的运行日志移到提示文本下方，日志框固定高度，默认只显示最后三条，点击展开全部、再点收起。
- 主页底部显示当前版本号；ToFA 徽标改为可点击，打开项目官网。
- 新增韩语、德语、法语语言包，随 Release 附件发布，可在“设置 → 语言”中导入。

### 手表端

- 修复长按菜单底部提示的抽搐：弦长内边距改为按固定锚点静态计算，不再随文字换行逐帧反馈，圆/方屏布局与动画保持不变。

### 文档

- README 下载区块补充语言包附件入口。

## 0.2.3 - 2026-11-14

### 手机端

- 导出方式中的“本机唯一码”更名为“唯一码”，四个导出选项固定排在同一行，不换行、不截断。
- 设置 → 关于新增“版本更新日志”，按版本列出更新内容并覆盖到当前版本。

### 文档

- GitHub 与 Gitee 分别维护平台版 README：各自平台作为第一下载入口，对端仅作为镜像。
- README 移除 Markdown 表格与英文板块，长链接改为独立成行的说明性链接。
- 双端 README 的镜像改为指向对端仓库主页，下载区块固定在标题与简介之后的最上方。
- Gitee 版 README 补充手机下载 APK 被存成 `.apk.zip` 的处理说明（Gitee 附件接口按 `application/zip` 返回，文件本身未变）。

## 0.2.2 - 2026-11-14

### 手机端

- 编辑模式点按条目后可直接查看密钥，密钥只读不可修改，点按即可复制。

## 0.2.1 - 2026-11-14

### 手机端

- 设置中的“传递”更名为“导入导出”，新增每行一个 `otpauth://` 链接的 TXT 导出。
- 主页新增编辑模式，支持改名、删除确认与长按拖动排序，并移除常驻拖动把手。
- 修复导入导出页面的返回动画，系统返回手势改为返回上一页。

### 手表端

- 系统返回手势优先关闭当前弹层或返回上一页，不再直接从子页面退出应用。

## 0.2.0 - 2026-11-13

### 手机端

- 提供离线 TOTP 账号管理、扫码 / 手输导入、加密备份与恢复。
- 支持应用锁、最近任务隐私、剪贴板保护和安全设置。
- 支持通过本地 adb 向手表同步账号、主题、语言与激活数据。
- 提供多语言与离线语言包导入、深浅色主题和自定义主题色。
- 浅色与深色模式统一保留原始明亮主题色，按钮前景色按亮度适配。
- 完善首次启动隐私说明、安全说明和开源许可页面。

### 手表端

- 支持圆屏 / 方屏、离线验证码、倒计时环、复制与二维码展示。
- 支持账号管理、应用锁、主题色、语言包和本地激活。
- 圆形页面可配置，右侧滚动进度条仅在运动时显示并贴合右弧。
- 浅色与深色模式统一保留原始明亮主题色，按钮前景色按亮度适配。
- 优化英文长文本、圆屏内容边距和页面滚动表现。
