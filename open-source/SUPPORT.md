## 常见问题

### 没有网络能不能生成验证码？

可以。TOTP 在本地根据密钥和设备时间生成，不需要账号或互联网服务。若时间偏差较大，验证码可能失败，请校准系统时间。

### 为什么手机端有 `INTERNET` 权限？

它用于手机与手表之间的本地 adb / 无线调试连接。Android 将本地 socket 通信也归入该权限；项目不依赖互联网后端。未使用“传递”功能时，可关闭手表无线调试。

### 手表收不到手机数据？

检查双端是否在同一局域网、手表无线调试是否开启、IP 与端口是否正确，以及是否允许了 ADB 授权。结束后建议关闭无线调试。

### 更换手机或手表后如何迁移？

先在旧手机端导出加密备份，再在新设备导入。手表数据可由手机重新推送。导出文件应离线妥善保存，不要上传到公开位置。

### 验证码不正确怎么办？

确认密钥、算法、位数和周期与服务端设置一致，并检查设备时间。不要在公开 Issue 中粘贴真实密钥或当前验证码。

## 提交使用问题

普通问题请使用 GitHub Issue；Gitee 镜像也可按仓库当前设置接收 Issue。一个 Issue 只描述一个问题，并包含：

- 手机端 / 手表端版本与 Android 版本。
- 设备型号、圆屏 / 方屏、浅色 / 深色等相关配置。
- 最小复现步骤、预期结果和实际结果。
- 脱敏截图或日志。

请勿附带真实密钥、激活码、应用锁密码、完整备份或私人信息。安全漏洞请改走 [SECURITY.md](SECURITY.md) 的私密渠道。

## 功能建议与贡献

功能建议请说明使用场景、现有问题和期望结果，而不仅是“增加某功能”。愿意提交代码或翻译时，请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。

本项目由维护者按实际情况处理 Issue，不承诺即时回复或远程协助。
